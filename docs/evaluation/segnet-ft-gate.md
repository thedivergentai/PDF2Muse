## Gate decision

**Do not start licensed `seg_net` fine-tuning yet as the primary bet.**

Autopsy warrants keeping the FT path **open and instrumented**, but the
majority sample-level dominant labels are insert/duration (alignment and
builder), with clef/layout as the strongest pitch-related signal. Fine-tuning
`seg_net` alone does not fix track grouping or full-page pianoform structure.

### Required before any FT promotion

1. **No-op checkpoint control** — run held-out tier1b with `oemer-custom`
   pointing at a copy of stock weights (identical bytes). Expect OMR-NED ≈
   `dpi360-quality-step128` baseline; any large swing is harness noise.
2. **Licensed segmentation labels** — DeepScores-style (or cleared equivalent)
   notehead / clef / accidental masks; fixed train/val splits; no MusicXML-only
   pseudo-labels as the sole supervision.
3. **Promotion rule** — promote only if held-out avg OMR-NED beats the locked
   dpi360 + quality step128 baseline **without** parse regressions.
